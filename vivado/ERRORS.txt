destination reset is the new processing-clock reset. Arithmetic IP unchanged.
Evidence: logs/simulate_03_apply_failure.log; pre-fix waveform in artifacts.

- BD 41-2384: BRAM native address ports are 32 bits, controllers/loader use
  13 bits for 8 KiB memories. Vivado zero-extends the high bits. Configuration
  word readback/loading and shared BRAM smoke tests pass; the entire BRAM
  address space is not exhaustively tested. No artificial width change made.
- IP_Flow 19-5661: processing clock has no associated bus. It clocks arithmetic;
  only axi_sys_clk is associated with AXI. This separation is intentional.
- VRFC 10-3705 warnings arise in AMD PS7 VIP / FIFO behavioral-model internals.
  They did not prevent elaboration or assertions from passing. Vendor models
  were not edited; behavior is not a substitute for hardware CDC/timing checks.
- Behavioral FIFO models omit synchronization delay and BRAM models cannot
  precisely validate simultaneous collision behavior. No such timing claim made.
- BD 41-2937 / 41-2925 and Vivado-projutils-10 in export: exported Tcl requires
  the local custom IP repositories / RTL files. These files are present and
  the final project audit found zero missing source files; keep this tree intact.
- PS7's generic EMIO SPI_0 SSIN-high reminder still prints during forced
  validation, even with the explicit spi0_ss_idle constant-high net connected;
  that connection is recorded in final_audit.txt. filemgmt 56-443 defaults an
  unspecified ECC algorithm to ECC_NONE; no ECC capability is claimed here.
- Reference COE file paths were unavailable when importing the original BD;
  Vivado reset initialization files to default. Runtime software must write
  the complete LQG configuration and DMA descriptors before use. Testbench
  explicitly writes its configuration, not dependent on stale BRAM contents.
- ADC channel 2 is disabled by original BD (LQG yk1=0). ADC bus CDC and the
  250 MHz DAC-clock / 15.625 MHz data relationship require actual-board review.
- Physical board revision/part/pinout and electrical timing remain unconfirmed.
  Target is reference Red Pitaya xc7z020clg400-1, not automatically ZCU104.
- No arbitrary-coefficient LQG closed-loop, saturation/rounding boundary,
  sustained DMA data transfer, real DDR, Linux software or physical board test.
- Earlier Model Composer post-export API exception is outside this Vivado run;
  the already patched/tested IP was reused byte-for-byte at HDL level.
